# DEV-SAMPLE - Gestione attività

## Obiettivo

Completare la web application fornita. Tutti i file necessari sono già presenti.

L'applicazione deve:

1. mostrare con `GET /api/items` la lista delle attività;
2. permettere di aggiungere un'attività con `POST /api/items`;
3. rifiutare con HTTP 400 un nome vuoto;
4. mostrare dal frontend HTML/JavaScript gli elementi restituiti dall'API;
5. permettere l'inserimento dal form senza ricaricare la pagina.

Non è richiesto un database: i dati possono restare in memoria.

## Domande

Al termine compilare `domanda1.txt` e `domanda2.txt` senza rinominare i file.

## Valutazione

Parte tecnica: 0-20. Domande: 0-10.

Non modificare o eliminare `.exam-id`.
